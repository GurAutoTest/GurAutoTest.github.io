CODEMARCA — PHASE-1 v3 (2026-10-21)
What changed since v4-phase-1-v2 (2026-10-17). Where this file and the v1/v2 notes disagree, this file wins.
Open with a local server, hard refresh (Cmd+Shift+R).

1. FEATURES PAGE (NEW)                               features.html, assets/features/
   26 feature cards in 5 groups, by moment: 01 When someone scans you, 02 Keep in touch,
   03 When something goes missing (dark band), 04 You're in control, 05 The sticker.
   Each card = visual + title + one line; black "New" pill on Phase-1 features.
   Visuals: 17 real-screen crops (assets/features/), studio photos, one four-theme strip.
   Linked from: site menu (Features, 3rd), every footer's Product list, homepage "See everything it does".

2. HOMEPAGE THEME REEL (NEW)                          theme-reel.js, theme-reel.css, assets/themes/reel/
   Right after the fact strip (#themes). 12 cards, every theme + version, full-length page shots.
   Autoplay; pauses on hover/focus. Mouse drag + flick, 2-finger trackpad, phone swipe.
   Slim scroll bar under it (drag/click to jump). No hint line.
   Hover (laptop) = the card scrolls to its end + frosted "Use this theme ↗"
   -> signup.html?theme=<id> -> onboarding.html?theme=<id> opens on that theme.
   Hero arc's 6 profile cards use the same shots (no title over the phone); the arc can be dragged /
   swiped too; the hover pill is laptop-only.

3. THEME CARRIED THROUGH SIGN-UP                      signup.html, onboarding.html
   signup.html passes ?theme= on to onboarding; onboarding applies it after the preview is set up.
   Unknown theme ids are ignored.

4. PHOTO RIVER                                        drag-loop.js (NEW)
   "Seen in the wild / Stuck on literally everything." — same title on homepage, how-it-works and about.
   drag-loop.js wires every .river__row itself: slow drift + mouse drag + thumb swipe + press-and-hold
   + 2-finger trackpad.

5. SMOOTH SCROLL, NO SNAP                             smooth-scroll.js (NEW), assets/vendor/lenis.min.js, site-end.css
   Section snap removed from the website. The 9 marketing pages (homepage, about, how-it-works,
   features, contact, privacy, terms, refund, shipping) ease the mouse wheel with Lenis 1.3.11
   (vendored, oreo.com-style). Phones keep native touch scroll. Reduced motion = off.
   Sections are still at least one screen tall. Do NOT bring page snap back.
